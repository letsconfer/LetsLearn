2. Letter C Pronunciation Rules (Hard K vs Soft S)

French: La Lettre C / Pronunciation: ला लेत्र से
Topic Details / Definition Rules, Logics & Pronunciation Correct Examples Incorrect Examples
Hard 'K' vs Soft 'S' • Soft 'S' (स): When C is followed by e, i, y (e.g., recette, garçon, ici, cyberspace, français).
• Hard 'K' (क): When C blends with a, o, u, appears at the end of a word, or precedes any consonant except H (e.g., Canada, école, rayon, culture, tabac, avec).		 • ici (here) — ee-see / ईसी

• école (school) — ay-kohl / एकोल

• tabac (tobacco) — tah-bah / तबाँ 		• ici as 'iki'

• ecole as 'esol'

3. Letter G Pronunciation Rules (Hard G vs Soft Zh)

Hard 'G' (ग) & Soft 'Zh' (ज/झ) • Hard G (ग): Followed by a, o, u, Gu + vowel, or before any consonant except N (e.g., gaspiller, aigu, gourmet, ongle, vague, guide, Guyane).
• Soft Zh (ज/झ): Followed by e, i, y (sound like 's' in treasure) (e.g., rouge, gillet).		 • guide (guide) — geed / गीद

• rouge (red) — roozh / रूझ

• gillet (vest) — zhee-lay / जीले 		• guide as 'jweed'

• rouge as 'roug'

4. Letter H Rules (Silent H & Vowel Borrowing)

The Silent H (*H Muet*) The letter H is usually completely silent if it appears at the start or end of a word.
Im Rule: When a word starts with 'h', it gives the sound of the following vowel and allows elision/liaison (e.g., l'hiver).		 • huit (eight) — weet / वीत

• Henri (Henry) — ahn-ree / आँरी

• l'hiver (the winter) — lee-vair / लीवेर

• horloge (clock) — ohr-lohzh / ओरलोझ 		• huit with aspirated 'H'

• Henri with 'H' sound

6. Letter R & -ER Ending Rules

French: La Lettre R et les Verbes en ER / Pronunciation: ला लेत्र एर ए ले वेर्ब ऑँ एर

Uvular R & -ER Suffix Rule • Letter R: Produced in the throat (r/ev/er sound) (e.g., rarement, la renaissance, la rue, Robert).
• -ER Suffix: When verbs/nouns end in -er, it produces a clear 'ay' (ए) sound (e.g., chanter, parler, travailler).		 • chanter (to sing) — shahn-tay / शांते

• parler (to speak) — parl-ay / पार्ले

• travailler (to work) — trah-vah-yay / त्रावाये 		• chanter as 'chan-ter'

• parler as 'par-ler'

7. Letter S Pronunciation Rules (Hard S vs Voiced Z)

Hard 'S' vs Voiced 'Z' Liaison • Hard 'S' (स): At the start of a word, double ss, after consonants, or before consonants (e.g., santé, sportif, bonsoir, dessin, sciences).
• Voiced 'Z' (ज़): When positioned between two vowels or forming a liaison (e.g., musée, télévision, voisin, elles ont, les animaux).		 • santé (health) — sahn-tay / साँते

• musée (museum) — moo-zay / मुजे

11. Two-Letter Blend: ILL

French: Le Son ILL / Pronunciation: ल सों इल
Topic Details / Definition Rules, Logics & Pronunciation Correct Examples Incorrect Examples
ILL Sounds as 'Y' (with exceptions) • Standard Rule: ILL produces a soft 'y' sound (like yes) (e.g., détail, soleil, famille).
• Exceptions: Words where ILL sounds like hard 'eel' (e.g., mille, million, village, tranquille, ville).		 • soleil (sun) — so-lay-yuh / सोलेय

• famille (family) — fah-mee-yuh / फ़ामिय

• mille (thousand) — meel / मील (exception) 		• soleil as 'sol-il'

• mille as 'mil-yuh'

12. Two-Letter Blend: QU

French: Le Son QU / Pronunciation: ल सों कू
Topic Details / Definition Rules, Logics & Pronunciation Correct Examples Incorrect Examples
QU Sounds as 'K' (क) The letter combination QU in French always produces a crisp 'k' sound (the 'u' is silent, serving only to modify the consonant sound).
