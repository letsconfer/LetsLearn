📌 Pronoun & Ending Rule for '-ER'

To conjugate any regular "-er" verb (e.g., parler), drop the -er stem and apply these pronoun endings:

  • Je (I): Add -e → Je parle [zhuh parl] (झ़् पर्ल)
  • Tu (You - informal): Add -es (silent) → Tu parles [too parl] (त्यू पर्ल)
  • Il / Elle / On (He / She / One): Add -e → Il / Elle parle [eel / el parl] (इल / एल पर्ल)
  • Nous (We): Add -ons → Nous parlons [noo par-lohng] (नू पर्लों)
  • Vous (You - formal/plural): Add -ez → Vous parlez [voo par-lay] (वू पर्ले)
  • Ils / Elles (They): Add -ent (silent) → Ils / Elles parlent [eel / el parl] (इल / एल पर्ल)
